# Декларация использования искусственного интеллекта

**Проект:** учебный сайт выставки «Заключённое»  
**Автор:** Князев Максим Денисович  
**Период работы:** октябрь 2026 года

Для работы я предоставил свой черновой HTML-код в `index.html` и черновые CSS-файлы из папки `stylesheets`. Дальше мы вместе с ИИ дорабатывали их: упорядочивали структуру, уточняли оформление блоков и добавляли элементы, которых не было в моей исходной версии. Для отдельных дополнений ИИ предлагал и писал фрагменты разметки и стилей.

Агента Figma я использовал для адаптации фреймов под техническую специфику учебного сайта ВШЭ и подготовки макета к дальнейшей вёрстке.

## Записи о запросах

Записи относятся к работе в течение октября и сгруппированы по этапам. Формулировки запросов сокращены и переданы по смыслу.

### Запись №1 · Адаптация фреймов

**Раздел:** макет сайта в Figma.

- **Что хотел сделать:** подготовить существующие фреймы к техническим условиям учебного сайта ВШЭ.
- **Запрос по смыслу:** адаптировать фреймы с учётом технической специфики сайта, чтобы дальше работать с ними при вёрстке.
- **Что предложил ИИ:** агент Figma помог привести фреймы к структуре, которую можно использовать при экспорте.
- **Что определил сам:** назначение фреймов, используемый макет и технические условия учебного задания.

### Запись №2 · Структура моего чернового HTML

**Раздел:** `index.html`.

- **Что хотел сделать:** упорядочить мой черновой HTML-код и сделать структуру страницы понятнее.
- **Запрос по смыслу:** помочь разделить существующую разметку на логические блоки и предложить, как организовать их внутри одной страницы.
- **Что предложил ИИ:** использовать отдельные блоки для каждого обособленного смыслового фрагмента сайта.
- **Что определил сам:** предоставил свой черновой `index.html`, определил вектор работы, формат и задал рамки.

### Запись №3 · Совместная доработка CSS

**Раздел:** папка `stylesheets`.

- **Что хотел сделать:** доработать мои черновые CSS-файлы, чтобы текст, изображения и карточки занимали нужное место на странице.
- **Запрос по смыслу:** Посмотри референс, помочь организовать стили, настроить ширину блоков, расстояния между ними и выравнивание через простые CSS-свойства.
- **Что предложил ИИ:** использовать `display: flex`, `width`, `gap`, `margin`, `padding` и `justify-content` для размещения элементов. Часть новых CSS-правил была подготовлена ИИ. Правила адаптации страницы к разным устройствам написал ИИ.
- **Что определил сам:** передал собственные стили, задал ограничение и предоставил референс оформления. Дальнейшая доработка предоставленных CSS проходила совместно с ИИ.

### Запись №4 · Карточки историй и иллюстрации

**Раздел:** истории участников и графика страницы.

- **Что хотел сделать:** разместить три истории в ряд, чтобы изображение, заголовок и описание каждой истории воспринимались как одна карточка.
- **Запрос по смыслу:** предложить простой способ собрать карточки и сохранить понятное расположение текста под изображениями.
- **Что предложил ИИ:** объединить содержимое каждой истории в отдельный `article`, а карточки расположить через `flex` с одинаковыми отступами. Сложные иллюстрации из макета использовать как отдельные изображения с подключением через `img`.
- **Что определил сам:** выбрал макет и разрешил упростить часть визуального оформления, чтобы не усложнять код большим количеством вложенных элементов.

### Запись №5 · Кнопка «Поделиться историей»

**Раздел:** блок «Расскажите о своей свадьбе».

- **Что хотел сделать:** добавить кнопку и окно с формой, которых не было в моём первоначальном черновом HTML. В текущей версии страницы ссылка подписана «Отправить историю».
- **Запрос по смыслу:** реализовать предусмотренное макетом окно для своей истории с помощью простых HTML и CSS.
- **Что предложил ИИ:** сделать ссылку `href="#story-form"` и отдельный блок с `id="story-form"`. Сначала окно скрывается через `display: none`, а правило `.modal:target` показывает его после перехода по ссылке. Ссылка «Закрыть» переводит к нижнему блоку страницы и скрывает окно.
- **Какие дополнения появились с помощью ИИ:** поля имени, электронной почты, даты и места свадьбы, текстовое поле для истории, выбор файлов и оформление окна. ИИ предложил способ реализации и подготовил соответствующие фрагменты HTML и CSS.
- **Что определил сам:** задал требование и использования формы из макета. Сам элемент был предусмотрен дизайном; техническое решение для его реализации предложил ИИ.

### Запись №6 · Адаптивная вёрстка для разных устройств

**Раздел:** CSS-правила для компьютеров, планшетов и телефонов.

- **Что хотел сделать:** сохранить читаемость и понятное расположение блоков при изменении ширины экрана.
- **Задача в рамках доработки сайта:** подготовить адаптивные стили для разных устройств.
- **Что написал ИИ:** медиазапросы `@media (max-width: 1000px)` и `@media (max-width: 650px)`, изменение размеров шрифта, ширины блоков и отступов. На узком экране колонки и карточки перестраиваются в один столбец, а элементы меню и строк билетов переносятся. Эти адаптивные CSS-правила были написаны ИИ.
- **Мой вклад:** предоставил исходные черновые стили и задал требование сохранять простой код. Написание адаптивных правил относится к вкладу ИИ.

## Выводы

Я начал работу со своего чернового HTML и черновых CSS. ИИ помог упорядочить их и предложил способы реализации элементов, для которых в исходном коде ещё не было решения. Особенно это относится к кнопке «Поделиться историей», окну формы и его открытию через CSS `:target`.

В ходе доработки я задавал требования к структуре и сложности сайта, выбирал макет и разрешал упрощать декоративные детали. С помощью ИИ появлялись новые фрагменты HTML и CSS, поэтому его участие включало практическую доработку кода. Адаптивные CSS-правила для компьютеров, планшетов и телефонов написал ИИ. Агент Figma отдельно помог адаптировать фреймы к технической специфике учебного сайта ВШЭ.

Основная сложность состояла в том, что точное воспроизведение всех деталей макета могло сделать код слишком подробным.
