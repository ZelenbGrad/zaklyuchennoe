# Заключённое — Астероидный архив

Статический сайт выставки по макету Figma: 11 страниц на HTML и CSS.

Откройте `index.html` в браузере. Сборка не требуется, все изображения и шрифты включены.

GitHub Pages: ветка `main`, папка `/ (root)`.

Покупка билетов и отправка истории требуют сервера и в этой версии отключены.
